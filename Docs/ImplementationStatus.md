## 状态和数据

`AppStore` 是共享状态入口，写盘成功后才更新公开状态。资料、关系、钱包和库存放在 Application Support 下每个账号的独立目录，凭据验证信息存在 Keychain。删除先暂存目录以便错误恢复；启动时处理未完成删除目录。退出和删除会停止安排中的目录关系到达，并清除签到提醒。

`confirmedMutual` 与目录关系分开，目录关注不会授予真实发消息权限。固定目录的 `catalog` 与 `localOnly` 字段为开发接入边界，不是用户可切换模式。实际账号不自动关注其他用户。

视频使用单一共享 `AVPlayer`；切换分页、退出页面时停止。相机和录音有权限、错误处理与离开释放。录音为当前页面临时内容，关闭会删除。无法打开的照片回退至原创插画。
