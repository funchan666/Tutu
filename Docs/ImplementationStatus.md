## 状态和数据

`AppStore` 是共享状态入口，写盘成功后才更新公开状态。资料、关系、钱包和库存放在 Application Support 下每个账号的独立目录，凭据验证信息存在 Keychain。删除先暂存目录以便错误恢复；启动时处理未完成删除目录。退出和删除会停止安排中的目录关系到达，并清除签到提醒。

`confirmedMutual` 与目录关系分开，目录关注不会授予真实发消息权限。固定目录的 `catalog` 与 `localOnly` 字段为开发接入边界，不是用户可切换模式。实际账号不自动关注其他用户。

视频使用单一共享 `AVPlayer`；切换分页、退出页面时停止。相机和录音有权限、错误处理与离开释放。录音为当前页面临时内容，关闭会删除。无法打开的照片回退至原创插画。

## 需补充才能上线的内容

1. 开发团队、正式 Bundle ID/签名、Apple 登录配置；服务端账号认证、会话、删号接口与 Apple token 撤销流程。
2. 真实内容/关系/消息/房间服务、推送和音视频信令与传输、服务端权限校验。
3. 钱包结算、交易账户绑定、跨设备防重、退款追偿与礼物送达接口。当前本地交易记录不能替代服务端长期结算。
4. App Store Connect 商品与可用性；接通上述消费闭环后才能启用 `WalletService.commerceReady`，不能只翻开关就认定支付完成。
5. 真人头像、大图、动态、相册、真实视频及封面；当前没有下载任何网络人物照片或来源不明的视频。
6. 举报运营处理与状态回执；当前只有用户主动发送邮件的通道。
7. 经用户授权后的编译、真机权限/媒体/键盘/小屏/动态字体检查、Apple 登录、内购沙盒、AI、页面对照验收。
